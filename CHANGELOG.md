## [0.1.0] - 2026-11-09

### Added

- Laptop-hosted server with a QR code join link for phones on the same Wi-Fi
- One map, jetpack with fuel, one gun with magazine and reload
- Up to 8 players, respawn with spawn protection, scoreboard and kill feed
- Touch twin-stick controls for phones, keyboard and mouse for laptops
- Client prediction with reconciliation, and interpolation of other players
- Ping and FPS display
